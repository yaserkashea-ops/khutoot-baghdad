# هوم فود — معاينة ويب للزبون (Customer MVP)

واجهة عربية RTL تجريبية لمنتج **هوم فود** (أكل بيتي + مفرزنات منزلية في الكرادة).  
هذا المجلد مستقل عن تطبيق Flutter في جذر المستودع (`khutoot-baghdad`) ولا يعدّل كوده.

## التشغيل

```bash
cd homefood-web
npm install
npm run dev
```

ثم افتح العنوان الذي يطبعه Vite (عادة `http://127.0.0.1:5173`).

```bash
npm run build   # بناء الإنتاج
npm run preview # معاينة البناء
```

## ما يشمله العرض

1. بوابة المنطقة (الكرادة)
2. الرئيسية: طهاة قريبون + وجبات اليوم
3. ملف الطاهي (تقييمات، شارة مطبخ معتمد)
4. قائمة اليوم + طلب مسبق
5. متجر المفرزنات (تصنيفات، قطعة/وزن، مجمّد/مبرد)
6. السلة + الدفع نقداً عند الاستلام
7. خط زمني نصّي لحالة الطلب

## بيانات وهمية

كل الطهاة والأطباق والطلبات **mock** — لا يوجد خلفية حقيقية أو دفع فعلي.  
التالي المتوقع: تطبيقات Flutter للزبون/الطاهي + Supabase + لوحة إدارة.
