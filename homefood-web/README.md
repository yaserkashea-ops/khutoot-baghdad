# هوم فود — معاينة ويب متقدمة للزبون

واجهة عربية RTL متقدمة (mock) لمنتج **هوم فود**.  
مستقلة عن Flutter في جذر المستودع (`khutoot-baghdad`).

## التشغيل

```bash
cd homefood-web
npm install
npm run dev
```

عادةً على `http://127.0.0.1:5173`.

## الميزات في هذه المعاينة

- بوابة منطقة (الكرادة) + هوية بصرية دافئة RTL
- بحث وتصفية للطهاة والأطباق
- تفاصيل وجبة + تفاصيل مفرزن (قطعة/وزن)
- نوافذ طلب مسبق متعددة
- سلة محفوظة في `localStorage` + توصيل مجاني فوق حد
- دفع نقد عند الاستلام مع تحقق بسيط
- سجل طلبات + خط زمني للحالة
- حالات فارغة / أخطاء / توست خفيف وحركة بسيطة

## بيانات وهمية

لا خلفية حقيقية. التالي: Flutter زبون/طاهي + Supabase + Admin.
